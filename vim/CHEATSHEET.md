# Neovim チートシート

## 基本設定

| 項目 | 設定値 |
|------|--------|
| Leader キー | `<Space>` |
| インデント | 2スペース（Go/Rust は 4） |
| クリップボード | システム連携 |
| grep | ripgrep (`rg --vimgrep`) |
| マウス | 無効 |

---

## コアキーマップ

### 移動・編集

| キー | 動作 |
|------|------|
| `H` | 行頭へ |
| `L` | 行末へ |
| `<C-j>` | 下に空行挿入 |
| `<C-k>` | 上に空行挿入 |
| `Y` | 行ヤンク |
| `<Esc><Esc>` | 検索ハイライト消去 |

### タブ・ウィンドウ

| キー | 動作 |
|------|------|
| `<C-l>` | 次のタブ |
| `<C-h>` | 前のタブ |
| `<C-w>m` | ウィンドウ最大化トグル |
| `<C-f>` | ウィンドウ選択（winselector） |

### テキストオブジェクト（独自）

| キー | 対象 |
|------|------|
| `i8` / `a8` | 括弧 `()` |
| `i2` / `a2` | ダブルクォート `""` |
| `i7` / `a7` | シングルクォート `''` |
| `i@` / `a@` | バッククォート ``` `` ``` |

### Insert モード（Emacs 風）

| キー | 動作 |
|------|------|
| `<C-a>` | 行頭 |
| `<C-e>` | 行末 |
| `<C-f>` | 右移動 |
| `<C-b>` | 左移動 |
| `<C-k>` | 行末まで削除 |

## Telescope（ファジーファインダー）

| キー | 動作 |
|------|------|
| `<C-p>` | ファイル検索 |
| `mg` | grep 検索 |
| `mr` | 直前の検索を再開 |
| `mf` | バッファ内検索 |
| `mo` | 最近開いたファイル |
| `mb` | バッファ一覧 |
| `mc` | コマンド一覧 |
| `md` | 診断一覧 |
| `mh` | ヘルプ検索 |
| `<Leader>s` | ドキュメントシンボル |
| `mj` | **プロジェクト切り替え（ghq）** |

**検索結果内**:
- `<C-o>` → Quickfix へ送信
- `<C-l>` → Location list へ送信

## セットアップ（必要なツール）

### ghq（プロジェクト切り替えに必要）

```bash
# インストール
brew install ghq

# リポジトリ保存先を設定
git config --global ghq.root ~/dev
```

**基本的な使い方**:
```bash
# リポジトリをクローン
ghq get https://github.com/user/repo

# リポジトリ一覧
ghq list
```

Neovim 内では `mj` でプロジェクト切り替え可能。
