# 解説型

## 概要

技術トピックを教育的に解説する動画。穏やかな BGM で落ち着いた雰囲気。スライドを多用して視覚的に情報を整理し、ずんだもんが先生役、四国めたんが生徒役の掛け合い。

**向いている題材:**
- 技術概念の解説（○○とは？）
- ツール・ライブラリの使い方
- アーキテクチャパターンの説明
- ベストプラクティスの紹介

**動画の長さ:** 3-7分（標準）

## シーン構成

| シーン | BGM | 雰囲気 | 内容 |
|--------|------|--------|------|
| OP（導入） | `op-intro` | 軽快 | テーマ紹介、「今日は○○について解説するのだ！」 |
| 解説本編 | `comedy-bgm` | 穏やか | トピックを段階的に解説（2-4チャプター） |
| まとめ | `ending` | 温かい | 要点の整理、次のステップ |

## BGM 切替パターン

```markdown
[bgm: op-intro]        ← OP 開始
# オープニング
...

[bgm: comedy-bgm]      ← 解説パート開始
# ○○とは？
...
# 使い方
...

[bgm: ending]           ← まとめ開始
# まとめ
...
```

**注意:** 解説型では BGM は1-2曲で十分。`dramatic` は通常使わない。

## SE パターン

| SE | タイミング | 使用頻度 |
|----|-----------|---------|
| `reveal` | 重要な概念の提示 | ★★ やや多い |
| `ding` | ポイントのまとめ | ★★ やや多い |
| `shock` | 意外な事実（あれば） | ★ 少ない |
| `fail` | よくある間違い | ★ 少ない |
| `crickets` | 基本使わない | ☆ ほぼなし |

## 表情パターン

穏やかな遷移。`default`, `happy`, `thinking` が中心。

**OP:**
`happy` → `default`

**解説パート:**
`default`(説明) → `thinking`(考察) → `default`(続き) → `surprise`(発見) → `happy`(理解)
→ 次のトピックで `default` に戻る

**まとめ:**
`default`(整理) → `happy`(締め)

**注意:** コードレビュー型と異なり、`angry`, `shock` はほぼ使わない。`sad` も控えめ。

## 口調ガイド

### ずんだもん（先生役）
- 分かりやすく噛み砕いて説明する
- 「つまり○○ということなのだ」で言い換え
- 具体例を挙げる「例えば○○なのだ」
- 難しい概念は段階的に「まず○○なのだ。次に○○なのだ」

### 四国めたん（生徒役）
- 質問を投げかける「それってどういうこと？」
- 理解を示す「なるほど、つまり○○ってことね」
- 初心者の疑問を代弁「でも○○の場合はどうなるの？」
- 要点をまとめる「整理すると、ポイントは○○ね」

## 原稿テンプレート

```markdown
# オープニング

[bgm: op-intro]

> # 【テーマ】を解説するのだ！
> 初心者にもわかる○○入門

[ずんだもん:happy] みなさんこんにちは、ずんだもんなのだ！
[四国めたん:happy] 四国めたんよ。よろしくね。

[ずんだもん:default] 今日は○○について解説するのだ！
[四国めたん] ○○？聞いたことはあるけど、詳しくは知らないわね。

[ずんだもん:smug] 大丈夫なのだ、分かりやすく説明するのだ！

# ○○とは？

[bgm: comedy-bgm]

> ## ○○とは
> - ポイント1
> - ポイント2
> - ポイント3

[ずんだもん:default] まず○○とは、△△のことなのだ。
[四国めたん:thinking] ふむふむ。つまり○○ということかしら？

[ずんだもん] そうなのだ。もう少し具体的に言うと、○○なのだ。
[四国めたん:default] なるほどね。

> ## なぜ○○が必要なのか
> - 理由1
> - 理由2

[ずんだもん:thinking] なぜ○○が必要かというと、△△だからなのだ。
[四国めたん:surprise] あら、それは重要ね。

# 使い方

> ## 基本的な使い方
> ```
> コード例
> ```

[se: reveal]
[ずんだもん:default] 実際の使い方を見ていくのだ。
[四国めたん] 具体例があると分かりやすいわね。

[ずんだもん] まず○○するのだ。次に○○するのだ。
[四国めたん:happy] なるほど、意外とシンプルね。

> ## よくある間違い
> - NG例
> - 正しいやり方

[se: fail]
[ずんだもん:sad] ちなみに、よくある間違いがあるのだ。
[四国めたん:default] どんな間違い？

[ずんだもん:angry] ○○してしまうパターンなのだ。これはダメなのだ。
[四国めたん:thinking] 確かに、それだと○○になっちゃうわね。

# まとめ

[bgm: ending]

> ## まとめ
> - ポイント1: ○○
> - ポイント2: △△
> - ポイント3: □□

[ずんだもん:default] というわけで今日のまとめなのだ！
[se: ding]
[ずんだもん:happy] ポイントは3つなのだ。1つ目は○○、2つ目は△△、3つ目は□□なのだ。
[四国めたん:happy] 分かりやすかったわ。○○について理解が深まったわね。

> ## 次のステップ
> - 公式ドキュメント: URL
> - おすすめ記事: URL

[ずんだもん:default] もっと知りたい人は公式ドキュメントを見てほしいのだ。
[四国めたん] リンクは概要欄に貼っておくわね。

[ずんだもん:happy] というわけで今日の解説は以上なのだ！いいねとチャンネル登録よろしくなのだ！
[四国めたん:happy] またね。ごきげんよう。
```
