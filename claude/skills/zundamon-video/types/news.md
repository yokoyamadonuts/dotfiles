# ニュース型

## 概要

テックニュースを速報風に紹介する動画。テンポが速く、複数のトピックを短いチャプターで次々に紹介する。ずんだもんがアンカー（MC）役、四国めたんがコメンテーター役。

**向いている題材:**
- 週次/月次のテックニュースまとめ
- 新サービス・新機能のリリース情報
- カンファレンスのハイライト
- 業界動向・トレンド紹介

**動画の長さ:** 3-5分（標準）

## シーン構成

| シーン | BGM | 雰囲気 | 内容 |
|--------|------|--------|------|
| 速報OP | `op-intro` | 軽快・テンポ速い | 「今週のテックニュース！」 |
| トピック1 | `comedy-bgm` | 軽快 | ニュース紹介 + コメント |
| トピック2 | `comedy-bgm` | 軽快 | ニュース紹介 + コメント |
| トピック3 | `comedy-bgm` | 軽快 | ニュース紹介 + コメント |
| まとめ | `ending` | 温かい | 一言コメント + 締め |

## BGM 切替パターン

```markdown
[bgm: op-intro]        ← OP 開始
# テックニュース速報
...

[bgm: comedy-bgm]      ← トピックパート
# トピック1
...
# トピック2          ← BGM は変えない（テンポ維持）
...
# トピック3
...

[bgm: ending]           ← まとめ
# まとめ
...
```

**ポイント:** トピック間で BGM を変えない。同じ BGM でテンポを維持し、チャプターだけで区切る。重大ニュースがあれば `dramatic` を1箇所だけ使ってもよい。

## SE パターン

| SE | タイミング | 使用頻度 |
|----|-----------|---------|
| `reveal` | 各トピックの冒頭 | ★★★ 多い |
| `ding` | ポジティブなニュース | ★★ やや多い |
| `shock` | 衝撃的なニュース | ★ 少ない |
| `fail` | 基本使わない | ☆ ほぼなし |
| `crickets` | 基本使わない | ☆ ほぼなし |

## 表情パターン

テンポ重視。素早い表情切替。

**OP:**
`happy` → `default`

**各トピック:**
`default`(紹介) → `surprise`(ポイント) → `thinking`(考察) or `happy`(好意的)
→ 次のトピックで `default` に戻る

**まとめ:**
`default` → `happy`(締め)

## 口調ガイド

### ずんだもん（MC / アンカー役）
- テンポよく紹介。「続いてのニュースなのだ！」
- 事実をコンパクトに伝える。1トピック3-5セリフ以内
- 「○○が△△を発表したのだ」「○○のバージョン△△がリリースされたのだ」

### 四国めたん（コメンテーター役）
- 短いコメントで反応。「それは大きいわね」「期待できそう」
- 影響を分析。「これが普及したら○○が変わるわね」
- ツッコミ少なめ（ニュースなので）。事実ベースのコメント

  - name: 四国めたん

**他の型との違い:**
- `slideTransitionMs: 400` — スライド切替を速く
- `speechGapMs: 150` — セリフ間を短く（テンポ重視）
- `paragraphGapMs: 300` — 段落間も短め

## 原稿テンプレート

```markdown
# テックニュース速報

[bgm: op-intro]

> # 今週のテックニュース！
> 【日付 or 期間】

[ずんだもん:happy] みなさんこんにちは、ずんだもんなのだ！
[四国めたん:happy] 四国めたんよ。
[ずんだもん:default] 今週のテックニュースをお届けするのだ！

# トピック1: 【見出し】

[bgm: comedy-bgm]

> ## 【トピック名】
> - ポイント1
> - ポイント2

[se: reveal]
[ずんだもん:default] まず1つ目のニュースなのだ。○○が△△を発表したのだ。
[四国めたん:surprise] あら、それは大きいわね。
[ずんだもん:thinking] ○○への影響が注目されるのだ。
[四国めたん:default] 今後の展開が気になるわね。

# トピック2: 【見出し】

> ## 【トピック名】
> - ポイント1
> - ポイント2

[se: reveal]
[ずんだもん:default] 続いてのニュースなのだ。○○のバージョン△△がリリースされたのだ。
[se: ding]
[四国めたん:happy] 待ってたわ！○○が追加されたのよね。
[ずんだもん:happy] そうなのだ。これで○○が便利になるのだ。

# トピック3: 【見出し】

> ## 【トピック名】
> - ポイント1
> - ポイント2

[se: reveal]
[ずんだもん:default] 最後のニュースなのだ。○○について△△が報じたのだ。
[四国めたん:thinking] ふむふむ。○○の影響はどうなのかしら。
[ずんだもん:thinking] まだ詳しいことは分かっていないのだ。続報に注目なのだ。

# まとめ

[bgm: ending]

> ## 今週のまとめ
> 1. 【トピック1の一言まとめ】
> 2. 【トピック2の一言まとめ】
> 3. 【トピック3の一言まとめ】

[ずんだもん:default] 以上、今週のテックニュースだったのだ！
[四国めたん:happy] 個人的には○○が一番注目ね。
[ずんだもん:happy] というわけで今日の動画は以上なのだ！いいねとチャンネル登録よろしくなのだ！
[四国めたん:happy] またね。ごきげんよう。
```

## バリエーション

### 単一トピック深掘り版

大きなニュース1つを深掘りする場合、トピック数を1つにして解説パートを厚くする。

```markdown
# 速報: ○○がリリース！

[bgm: op-intro]
> # 【大ニュースのタイトル】

[ずんだもん:surprise] 大ニュースなのだ！

# 何が変わったのか

[bgm: comedy-bgm]
（解説 3-5 セリフ × 2-3 チャプター）

# まとめ

[bgm: ending]
...
```
