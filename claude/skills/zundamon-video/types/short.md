# ショート型

## 概要

1-2分のショート動画。1つのトピックに集中し、最小構成でインパクトを出す。フック（つかみ）→ 解説 → オチの3パートで構成。YouTubeショートやTikTok向け。

**向いている題材:**
- 1つの Tips / 豆知識
- 「○○、知ってた？」系の小ネタ
- 1つのアンチパターン紹介
- ワンライナー・コードスニペット紹介

**動画の長さ:** 1-2分（厳守）

## シーン構成

| シーン | BGM | 雰囲気 | 内容 |
|--------|------|--------|------|
| フック | `comedy-bgm` | 軽快 | 冒頭5秒で興味を引く |
| 解説 | `comedy-bgm` | 軽快 | 本題を手短に説明 |
| オチ | `comedy-bgm` | 軽快 | 印象に残る締め |

## BGM 切替パターン

```markdown
[bgm: comedy-bgm]       ← 最初から最後まで1曲
# 【タイトル】
...
```

**ポイント:** ショート動画では BGM を切り替えない。1曲で通す。

## SE パターン

| SE | タイミング | 使用頻度 |
|----|-----------|---------|
| `reveal` | メインの事実公開 | ★ 1回 |
| `shock` | 衝撃的な場合のみ | ★ 0-1回 |
| `ding` | 基本使わない | ☆ なし |
| `fail` | 基本使わない | ☆ なし |
| `crickets` | オチで使えたら | ★ 0-1回 |

**合計 SE: 1-2個。** それ以上は使わない。

## 表情パターン

最小限の表情遷移。3-4種に限定する。

**基本パターン:**
`default`(フック) → `surprise`(事実) → `thinking` or `smug`(考察/オチ) → `happy`(締め)

**衝撃パターン:**
`smug`(フック) → `shock`(衝撃) → `sad` or `angry`(感想) → `happy`(締め)

## 口調ガイド

### ずんだもん
- **フック:** 強めの一言。「○○ってヤバいのだ」「知ってたのだ？」
- **解説:** コンパクトに。1文で1事実。
- **オチ:** 印象的な一言で終わる

### 四国めたん
- **リアクション:** 短く。「えっ」「うそでしょ」「なるほどね」
- **オチ:** 一言でまとめる or ツッコミ

### ショート特有のルール
- セリフは1行15文字以内を目指す（テンポ命）
- `<ruby>` は最小限（読み上げ速度優先）
- 合計セリフ数: 8-15行以内

## Frontmatter テンプレート

```yaml
---
fps: 30
width: 1080
height: 1920
speakerId: 3
slideTransitionMs: 300
speechGapMs: 150
paragraphGapMs: 200
fontFamily: "M PLUS Rounded 1c"
characters:
  - name: ずんだもん
    speakerId: 3
    position: right
    flip: false
    color: "#55B02E"
    overflowY: 0.5
    overflowX: 0.1
    height: 900
  - name: 四国めたん
    speakerId: 2
    position: left
    flip: true
    color: "#D85898"
    overflowY: 0.5
    overflowX: 0.1
    height: 960
---
```

**他の型との違い:**
- `width: 1080`, `height: 1920` — **縦型**（9:16）
- `slideTransitionMs: 300` — 切替を最速に
- `speechGapMs: 150` — テンポ最速
- `paragraphGapMs: 200` — 段落間も最短
- `height` を少し大きく（縦型画面に合わせる）

### 横型で作る場合

通常の YouTube ショートでも横型で投稿可能。その場合は `width: 1920`, `height: 1080` に戻す。

## 原稿テンプレート

```markdown
# 【キャッチーなタイトル】

[bgm: comedy-bgm]

> # 【タイトル】

[ずんだもん:smug] 【フック: 興味を引く一言】

> ## 【事実】
> - ポイント

[se: reveal]
[ずんだもん:surprise] 【衝撃の事実】
[四国めたん:shock] 【短いリアクション】

[ずんだもん:default] 【簡潔な解説 1-2文】
[四国めたん:thinking] 【コメント】

[ずんだもん:happy] 【オチ or まとめ】
[四国めたん:happy] 【締めの一言】
```

## 具体例: 「git の隠しコマンド」

```markdown
# git の隠しコマンド

[bgm: comedy-bgm]

> # git の隠しコマンド、知ってた？

[ずんだもん:smug] <ruby>git<rt>ギット</rt></ruby>に隠しコマンドがあるの、知ってたのだ？

> ## git blame --reverse
> 特定の行が**削除された**コミットを探せる

[se: reveal]
[ずんだもん:default] <ruby>git blame<rt>ギット ブレイム</rt></ruby>に<ruby>reverse<rt>リバース</rt></ruby>オプションをつけると、コードが消された犯人が分かるのだ。
[四国めたん:surprise] あら、普通のblameは追加した人しか分からないのよね。

[ずんだもん:happy] 「誰がこのコード消したのだ！？」ってときに使えるのだ。
[四国めたん:smug] 犯人捜しが捗るわね。
```

## 注意事項

- **1分を目指す。** 2分は上限。長くなったらチャプターを削る
- **スライド枚数:** 2-3枚が限度
- **掛け合い:** ずんだもん単体でもOK（テンポ優先なら1キャラ）
- **BGM 切替:** しない。1曲で通す
- **冒頭3秒で興味を引く:** 結論ファーストで「○○がヤバい」から始める
