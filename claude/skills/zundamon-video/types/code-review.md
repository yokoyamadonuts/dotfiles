# コードレビュー型

## 概要

ヤバいコードベースやアンチパターンをネタ的に暴露する動画。感情の起伏が激しく、BGM を4段階で切り替え、SE を多用する。ずんだもんが事実を提示し、四国めたんが大げさにリアクションする掛け合いが基本。

**向いている題材:**
- レガシーコードベースの紹介
- アンチパターン集
- 技術的負債の実態暴露
- コードゴルフ / 闇コード選手権

**動画の長さ:** 5-10分（標準）

## シーン構成

| シーン | BGM | 雰囲気 | 内容 |
|--------|------|--------|------|
| OP（導入） | `op-intro` | 軽快・脱力 | テーマ紹介、規模感の提示 |
| 本編（ネタ） | `comedy-bgm` | コミカル | ヤバいコードを次々に暴露 |
| 衝撃パート | `dramatic` | シリアス | セキュリティ問題、深刻な負債 |
| ED（まとめ） | `ending` | 温かい | 教訓、ポジティブな締め |

## BGM 切替パターン

```markdown
[bgm: op-intro]        ← OP 開始
# オープニング
...

[bgm: comedy-bgm]      ← 本編（ネタパート）開始
# 神クラス降臨
...

[bgm: dramatic]         ← 衝撃パート開始
# SQLインジェクション天国
...

[bgm: ending]           ← ED 開始
# エンディング
...
```

## SE パターン

| SE | タイミング | 使用頻度 |
|----|-----------|---------|
| `reveal` | 数値データの公開直前 | ★★★ 多い |
| `shock` | 衝撃的なコードの発覚 | ★★★ 多い |
| `fail` | セキュリティ問題、バグ | ★★ やや多い |
| `ding` | まとめのポイント | ★ 少ない |
| `crickets` | スベったジョーク、沈黙 | ★ 少ない |

**鉄板コンボ:**
```markdown
[se: reveal]
[ずんだもん:surprise] なんと○○なのだ！
[四国めたん:shock] ○○！？
```

## 表情パターン

感情の起伏が激しい。ジェットコースター的な表情遷移。

**OP:**
`happy` → `smug` → `default`

**本編（ネタ）:**
`default`(提示) → `surprise`(発覚) → `shock`(リアクション) → `angry`(批判) → `smug`(オチ) → `happy`(笑い)
→ 次のネタで `default` に戻る

**衝撃パート:**
`default`(導入) → `shock`(発覚) → `angry`(怒り) → `sad`(嘆き)

**ED:**
`default`(まとめ) → `thinking`(教訓) → `happy`(締め)

## 口調ガイド

### ずんだもん
- **OP:** テンション高め。「今日は○○を覗いてみるのだ！」
- **ネタ提示:** 淡々と事実を述べる → 数値でドン。「なんと○○行なのだ！」
- **衝撃:** ちょっと引く。「これはさすがにヤバいのだ…」
- **ED:** しみじみ。「動いてるっていうのは、それだけですごいことなのだ」

### 四国めたん
- **OP:** 軽いノリ。「あら、面白そうじゃない」
- **リアクション:** 大げさに驚く。「○○！？うそでしょ！」
- **ツッコミ:** キレ味鋭く。「それ、もう○○じゃない」
- **ED:** 優しめ。「でもね、忘れちゃいけないことがあるわよ」

## 原稿テンプレート

```markdown
# オープニング

[bgm: op-intro]

> # 【タイトル】
> 【サブタイトル】

[ずんだもん:happy] みなさんこんにちは、ずんだもんなのだ！
[四国めたん:happy] 四国めたんよ。よろしくね。

[ずんだもん:smug] 今日は○○を覗いてみるのだ！
[四国めたん] あら、○○。面白そうじゃない。

> ## 規模感
> - 数値1
> - 数値2

[se: reveal]
[ずんだもん:surprise] まずは規模感なのだ。○○が△△！
[四国めたん:shock] △△！？それはすごいわね。

# ネタ1: 【チャプター名】

[bgm: comedy-bgm]

> ## 【ネタのタイトル】
> 【ヤバいポイントを箇条書き】

[se: shock]
[ずんだもん:surprise] さっそくヤバいやつなのだ！
[四国めたん:shock] ○○！？

[ずんだもん:angry] しかも○○なのだ！
[四国めたん:smug] それ、○○じゃない。

# ネタ2: 【チャプター名】

> ## 【ネタのタイトル】
> 【ヤバいポイントを箇条書き】

[ずんだもん:default] 次は○○の話なのだ。
[se: reveal]
[ずんだもん:surprise] ○○が△△なのだ！
[四国めたん:shock] △△！？

# 衝撃パート: 【チャプター名】

[bgm: dramatic]

> ## 【深刻な問題のタイトル】
> 【問題の詳細】

[ずんだもん:default] ここからは深刻な話なのだ。
[pause: 300ms]
[se: fail]
[ずんだもん:shock] ○○が△△なのだ…
[四国めたん:angry] それはさすがにまずいわよ。

# エンディング

[bgm: ending]

> ## 教訓
> - ポイント1
> - ポイント2
> - ポイント3

[ずんだもん:default] というわけで、今日のまとめなのだ！
[pause: 300ms]
[se: ding]
[ずんだもん:thinking] 【教訓を語る】
[四国めたん:sad] 耳が痛い話ね。

> ## でも…
> 【ポジティブな締め】

[四国めたん:happy@あまあま] 【ポジティブなコメント】
[ずんだもん:thinking] たしかに。【同意】

[ずんだもん:happy] というわけで今日の動画は以上なのだ！いいねとチャンネル登録よろしくなのだ！
[四国めたん:happy] またね。ごきげんよう。
```
