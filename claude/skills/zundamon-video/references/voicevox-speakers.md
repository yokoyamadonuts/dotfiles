## API での話者確認方法

VOICEVOX API で利用可能な話者を動的に取得できる。

```bash
# 全話者一覧を取得
curl -s http://localhost:50021/speakers | jq '.[] | {name, styles: [.styles[] | {name, id}]}'

# 特定話者の詳細
curl -s http://localhost:50021/speakers | jq '.[] | select(.name == "ずんだもん")'

# ID のみ一覧
curl -s http://localhost:50021/speakers | jq '[.[] | .styles[] | {name: (.name), id: .id}]'
```

**注意:** VOICEVOX のバージョンによって利用可能な話者・スタイルが異なる。新しいバージョンでは追加キャラクターが含まれる場合がある。最新の一覧は `GET /speakers` で確認すること。
