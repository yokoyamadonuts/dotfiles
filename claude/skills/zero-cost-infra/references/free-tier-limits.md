## Cloudflare Workers

| 項目 | Free | Paid ($5/月~) |
|------|------|---------------|
| リクエスト | 10万/日 | 1,000万/月 |
| CPU 時間 | 10ms/リクエスト | 30s/リクエスト |
| スクリプトサイズ | 1MB | 10MB |
| Cron Triggers | 5 | 250 |
| サブリクエスト | 50/リクエスト | 1,000/リクエスト |

**注意:**
- Free プランの 10万リクエスト/日は UTC 基準でリセット
- CPU 時間は Wall time ではなく実行時間。I/O 待ちはカウントされない
- 超過時は 429 エラーを返す（リクエストがドロップされる）

## Cloudflare R2

| 項目 | Free |
|------|------|
| ストレージ | 10GB/月 |
| Class A 操作（PUT, LIST等） | 100万/月 |
| Class B 操作（GET等） | 1,000万/月 |
| エグレス（データ転送） | 無制限（無料） |

**R2 の最大の強み**: エグレス料金が無料。AWS S3 で高額になりがちなデータ転送コストがゼロ。

## Cloudflare D1

| 項目 | Free |
|------|------|
| 行読取 | 500万/日 |
| 行書込 | 10万/日 |
| ストレージ | 5GB |
| DB 数 | 50,000 |

**注意:**
- SQLite ベース。JOINや複雑なクエリもサポート
- ストレージ上限は全DB合計
- バッチ処理で行書込を効率化可能

## Cloudflare KV

| 項目 | Free |
|------|------|
| 読取 | 10万/日 |
| 書込 | 1,000/日 |
| リスト | 1,000/日 |
| ストレージ | 1GB |

**注意:**
- Eventually consistent（結果整合性）。リアルタイム性が必要な場合は D1 を使用
- セッション管理に使う場合、書込上限（1,000/日）に注意
- 大量の書込が必要な場合は D1 やDurable Objects を検討

## Cloudflare Queues

| 項目 | Free |
|------|------|
| メッセージ | 100万/月 |
| 操作 | 100万/月 |

**注意:**
- メッセージサイズ上限: 128KB
- バッチサイズ: 最大10メッセージ
- リトライ: 最大3回（設定変更可能）

## Turso

| 項目 | Free (Starter) |
|------|----------------|
| ストレージ | 9GB |
| 行読取 | 500M/月 |
| 行書込 | 25M/月 |
| DB 数 | 500 |
| ロケーション | 3 |

**D1 との比較:**
- Turso は複数リージョン対応（レプリカ）
- libSQL ベースで ORM サポートが豊富（Drizzle, Prisma）
- D1 は Cloudflare エコシステム統合が完璧

## Resend

| 項目 | Free |
|------|------|
| メール送信 | 3,000通/月 + 100通/日 |
| ドメイン | 1 |
| API キー | 1 |

**注意:**
- 日次上限（100通/日）があるので認証メール以外にも使う場合は注意
- Webhook でバウンス・開封追跡が可能
- Cloudflare Email Routing と組み合わせで受信も無料

## Better Auth

| 項目 | 詳細 |
|------|------|
| 料金 | 完全無料（OSS） |
| プロバイダ | Email/Password, Google, GitHub, Apple 等 |
| セッション管理 | DB ベース（D1 対応） |
| 2FA | TOTP 対応 |

**Workers との統合:**
- `kysely-d1` でD1に直接接続
- Request/Response ベースの API で Workers と相性が良い
- OAuth リダイレクトも Workers 上で完結

## 無料枠で対応可能な規模の目安

| 指標 | 概算値 |
|------|--------|
| DAU（日次アクティブ） | ~500 |
| ページビュー/日 | ~5,000 |
| API コール/日 | ~50,000 |
| DB 読取/日 | ~100万行 |
| ファイルアップロード/月 | ~5GB |
| メール送信/月 | ~3,000通 |

**超えるシナリオの例:**
- バイラルで急成長（→ Workers Paid $5/月 に移行）
- 画像が多い UGC サービス（→ R2 ストレージ超過に注意）
- リアルタイムチャット等の高頻度書込（→ KV の書込上限に注意）

## 有料プランへの移行判断

### いつ移行するか

| シグナル | 対応 |
|---------|------|
| Workers リクエストが 8万/日を常時超える | Workers Paid ($5/月) に移行 |
| D1 ストレージが 4GB を超える | D1 Paid or Turso Paid に移行 |
| R2 ストレージが 8GB を超える | R2 Paid ($0.015/GB) に移行 |
| Resend 月間 2,500 通を超える | Resend Pro ($20/月) に移行 |

### 移行のポイント

- **アーキテクチャ変更不要**: 従量課金モデルなので、プラン変更のみでスケール
- **段階的に移行**: 全サービス一括ではなく、ボトルネックのサービスから順次
- **コスト可視化**: Cloudflare Dashboard の Analytics を定期確認
