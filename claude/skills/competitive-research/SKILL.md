# 競合・技術リサーチスキル

## 概要

並列エージェントを活用して複数の競合・技術・ツールを同時に調査し、比較分析レポートを生成する。個別に順番に調べるのではなく、N個のエージェントを同時に走らせてN倍速で完了する。

## ユースケース

- プロダクトの競合分析（Asana vs Linear vs Monday.com 等）
- 技術選定のリサーチ（フレームワーク、ライブラリ、ツールの比較）
- 市場調査（トレンド、ユーザー動向、価格分析）
- OSS ライブラリの比較評価

## コアワークフロー

### ステップ1: リサーチ対象の特定

ユーザーに調査対象を確認する：

```javascript
AskUserQuestion({
  questions: [
    {
      question: "何を調査しますか？",
      header: "調査種別",
      options: [
        { label: "競合プロダクト", description: "競合他社のプロダクトを比較分析" },
        { label: "技術・ツール", description: "フレームワーク、ライブラリ、ツールの比較" },
        { label: "市場・トレンド", description: "市場動向やユーザートレンドの調査" }
      ],
      multiSelect: false
    }
  ]
})
```

### ステップ2: 調査対象のリストアップ

- ユーザーが指定した対象を使用
- または Web検索で主要な候補を特定（3〜5件が最適）

### ステップ3: 並列エージェントによる調査

各調査対象に対して1エージェントを起動する：

```javascript
// 例: 5つの競合を並列調査
Task({
  description: "Research [Target 1]",
  prompt: `以下の観点で [Target 1] を調査し、簡潔なレポートを作成せよ：

## 調査観点
1. 概要・ポジショニング
2. 主要機能・特徴
3. 価格体系
4. ターゲットユーザー
5. 強み・弱み
6. 最近のアップデート・方向性
7. ユーザーの評判・レビュー

Web検索を活用して最新情報を収集すること。`,
  subagent_type: "general-purpose"
})
// + Target 2, 3, 4, 5 を並列起動
```

### ステップ4: 比較マトリクスの作成

全エージェントの結果を統合し、比較マトリクスを作成する：

```markdown
# 競合分析レポート

生成日: [日付]

## エグゼクティブサマリー
[3つの主要インサイト]

## 比較マトリクス

| 観点 | Target 1 | Target 2 | Target 3 | Target 4 | Target 5 |
|------|----------|----------|----------|----------|----------|
| ポジショニング | | | | | |
| 主要機能 | | | | | |
| 価格 | | | | | |
| ターゲット | | | | | |
| 強み | | | | | |
| 弱み | | | | | |

## 個別レポート

### Target 1
[エージェント1の詳細レポート]

### Target 2
[エージェント2の詳細レポート]
...

## ホワイトスペース分析
[競合がカバーしていない領域・差別化機会]

## 推奨事項
[調査結果に基づく推奨アクション]
```

### ステップ5: ギャップ分析とインサイト

比較マトリクスから以下を抽出する：
- **ホワイトスペース**: 競合がカバーしていない領域
- **テーブルステークス**: 全社が提供している必須機能
- **差別化要素**: 各社がユニークに提供している機能
- **トレンド**: 各社が向かっている方向性
- **機会**: 自社が活用できるギャップ

## 出力ファイル

- `docs/research-[topic].md` - 統合レポート
- `docs/research-[topic]-[target].md` - 個別レポート（任意）

## 関連スキル

- **product-strategy**: 競合リサーチの結果を戦略策定に活用
- **write-prd**: 競合分析を踏まえたPRD作成
- **devils-advocate**: 競合分析の仮定をストレステスト
- **japanese-tech-writing**: 比較分析レポートの本文を執筆・推敲する際の日本語文章規範
