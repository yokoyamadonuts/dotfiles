# ローンチ戦略スキル

## 概要

インディープロダクトのローンチは1回限りのイベントではなく、**計画的なキャンペーン**。Marc Lou方式のティーザー戦略と、マルチプラットフォーム同時ローンチで初動のインパクトを最大化する。

## なぜ重要か

- 「ローンチして待つ」は最悪の戦略
- Product Huntだけに頼ると1日で忘れられる
- 複数プラットフォームでの同時露出が初動の鍵
- ローンチ後のフォローアップが長期的な成長を決める

### ステップ2: ローンチタイムライン策定

#### T-7日: ティーザーフェーズ（Marc Lou方式）

**目的**: 期待感を醸成し、ローンチ日に集中的な注目を集める

- [ ] ティーザー動画/GIF（15-30秒、プロダクトのコア体験を見せる）
- [ ] ランディングページ公開（メール登録フォーム付き）
- [ ] X投稿: 「来週、[問題]を解決する[プロダクト]をローンチします」
- [ ] Build in Publicコンテンツ: 開発の舞台裏を共有

#### T-3日: 事前準備フェーズ

- [ ] Product Huntのcoming soonページ作成
- [ ] プレスキット準備（スクリーンショット、説明文、ロゴ）
- [ ] Xスレッド下書き（ストーリー形式）
- [ ] Reddit投稿下書き（各サブレディット用）
- [ ] ローンチ日のメール下書き（メールリストがある場合）
- [ ] デモ動画の最終確認

#### T-1日: 最終確認

- [ ] `ship-check` スキルで品質監査
- [ ] 決済フローのテスト（Stripeテスト決済）
- [ ] ランディングページの最終確認
- [ ] 全投稿の下書き最終確認
- [ ] Product Huntハンター/サポーターへの連絡

#### ローンチ日: 同時展開

**時間**: 太平洋時間 00:01（Product Huntのリセット時間）

| 時間 | プラットフォーム | アクション |
|------|----------------|-----------|
| 00:01 PST | Product Hunt | ローンチ投稿 |
| 06:00 PST | X (Twitter) | ローンチ告知 + Xスレッド |
| 07:00 PST | Reddit | 関連サブレディットに投稿 |
| 08:00 PST | Hacker News | Show HN投稿 |
| 09:00 PST | メールリスト | ローンチメール送信 |
| 随時 | IndieHackers | ローンチ報告投稿 |

#### T+1〜3日: フォローアップ

- [ ] Product Huntのコメントに全返信
- [ ] 初期ユーザーからのフィードバック収集
- [ ] バグ報告への迅速対応
- [ ] 「ローンチ結果報告」投稿（数字を共有）

#### T+7日: 振り返りと次のステップ

- [ ] ローンチ結果の分析（トラフィック、サインアップ、有料転換）
- [ ] 学びの記録（何が効いたか、何が効かなかったか）
- [ ] 長期マーケティング計画の策定
- [ ] `build-in-public` スキルでコンテンツ戦略開始

### ステップ3: チャネル別戦略

#### Product Hunt

```markdown
## Product Hunt 投稿テンプレート

タイトル: [プロダクト名] - [6秒説明]
タグライン: [問題]を解決する[ソリューション]
説明:
- 段落1: 何が問題か（共感を呼ぶ）
- 段落2: どう解決するか（デモGIF付き）
- 段落3: なぜ今か（ストーリー）
- CTA: 今すぐ試す

最初のコメント: 「こんにちは！[名前]です。このプロダクトを作った理由は...」
```

**Product Huntのコツ**:
- 火曜〜木曜にローンチ（週末は避ける）
- 最初のコメントで個人的なストーリーを語る
- 全コメントに丁寧に返信する
- Makerバッジを有効にする

#### X (Twitter)

```markdown
## Xスレッド テンプレート

1/7 🚀 [プロダクト名]をローンチしました

[問題の共感]を感じたことはありませんか？

2/7 今まで[既存の解決策]でやっていたけど、[不満点]だった

3/7 だから[プロダクト名]を作った

[デモGIF/スクリーンショット]

4/7 特徴:
- ✅ [特徴1]
- ✅ [特徴2]
- ✅ [特徴3]

5/7 技術的な裏側（Build in Public）
[スタック、開発期間、学び]

6/7 価格:
[価格情報]
ローンチ特別価格あり 🎉

7/7 試してみてください！
[URL]

感想やフィードバックは大歓迎です 🙏
```

#### Reddit

```markdown
## Reddit 投稿テンプレート

タイトル: [Show/I made] [プロダクト説明]

本文:
- 問題の説明（共感重視）
- 解決策の説明（宣伝っぽくしない）
- 技術的な詳細（Redditユーザーは好む）
- フィードバックの依頼
- URL（控えめに）
```

**Redditのコツ**:
- 宣伝っぽい投稿は即ダウンボートされる
- 技術的な詳細や裏話を多めに
- コミュニティに価値を提供する姿勢
- 適切なサブレディットを選ぶ

#### Hacker News

```markdown
## Show HN テンプレート

タイトル: Show HN: [プロダクト名] – [技術的に興味深い説明]

本文:
- 技術的なアプローチ
- なぜこう作ったか
- オープンソースコンポーネントがあれば言及
- URL
```

## 関連スキル

- **validate-idea**: ローンチ前のアイデア検証
- **ship-check**: ローンチ前の品質監査
- **build-in-public**: ローンチ後のコンテンツ戦略
- **analyze-data**: ローンチ結果の分析
- **japanese-tech-writing**: ローンチ計画の説明文を執筆・推敲する際の日本語文章規範

---

**覚えておくこと: ローンチは1回のイベントではなくキャンペーン。準備に1週間、実行に1日、フォローアップに1週間。マルチプラットフォーム同時展開で初動を最大化する。**
