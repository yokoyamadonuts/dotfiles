# Build in Public コンテンツ戦略スキル

## 概要

開発プロセス自体をコンテンツとして公開し、オーディエンスの構築とプロダクトの認知を同時に進める。Pieter Levels、Marc Lou、Jack Friksが実践する「1日1時間マーケティング」システムを体系化。

## なぜ重要か

- **プロダクトを作るだけでは誰も来ない**。配信チャネルが必要
- Build in Publicは**無料の広告**。自分の時間だけが投資
- 開発者コミュニティは透明性を好む。収益や失敗を共有すると信頼が生まれる
- ローンチ前からオーディエンスを構築できる

### ステップ2: コンテンツカテゴリの設定

4つのカテゴリからバランスよく投稿する：

#### 1. 進捗共有（40%）

日々の開発進捗をリアルタイムで共有する。

```markdown
## X投稿テンプレート: 進捗共有

### デイリー進捗
[プロダクト名] Day [N]:
- ✅ [今日やったこと]
- 🎯 明日: [予定]
[スクリーンショット/GIF]

### 機能リリース
🚀 [プロダクト名] に [機能名] を追加しました
[Before → After のGIF]
[機能の説明（2-3文）]
試してみてください → [URL]

### 問題解決
💡 [問題] にハマっていたけど、[解決策] で解決した
[コード/設定のスクリーンショット]
同じ問題の人の参考になれば 🙏
```

#### 2. 収益透明性（20%）

数字を公開して信頼を構築する。

```markdown
## X投稿テンプレート: 収益報告

### 週次/月次レポート
📊 [プロダクト名] Week [N] レポート:
- MRR: $[金額] ([前週比])
- 新規ユーザー: [数]
- チャーン: [数]
- 学び: [一文]

### マイルストーン達成
🎉 [プロダクト名] が MRR $[金額] を達成しました！

[N]ヶ月前にアイデアを思いついて、[N]日で作って、今ここまで来ました。

やったこと:
1. [施策1]
2. [施策2]
3. [施策3]

次の目標: $[金額]
```

#### 3. 技術的な学び（25%）

開発者コミュニティに価値を提供する。

```markdown
## X投稿テンプレート: 技術的学び

### 技術選択の理由
🛠️ [プロダクト名] のスタック:
- [技術1]: [選んだ理由]
- [技術2]: [選んだ理由]
- [技術3]: [選んだ理由]

[N]個のプロダクトを同じスタックで作っています。
スタック固定は最高の効率化。

### 失敗談
⚠️ [プロダクト名] で [技術/設計] を選んだのは失敗でした

問題: [何が起きたか]
原因: [なぜ起きたか]
解決: [どう直したか]
学び: [次回からどうするか]

### Tips/How-to
💡 [技術名] で [問題] を解決する方法:

1. [ステップ1]
2. [ステップ2]
3. [ステップ3]

[コード/設定のスクリーンショット]
```

#### 4. ストーリー（15%）

個人的なストーリーで感情的なつながりを作る。

```markdown
## X投稿テンプレート: ストーリー

### Why（なぜ作ったか）
[プロダクト名] を作った理由:

[問題に遭遇したストーリー]

「これは自分で解決できる」と思って週末で作りました。
今、[N]人が使ってくれています。

### 振り返り
[N]ヶ月前の自分に伝えたいこと:

1. [学び1]
2. [学び2]
3. [学び3]

インディー開発を始めて一番大きな変化は [一文]。
```

### ステップ3: 1日1時間マーケティングシステム（Jack Friks方式）

毎日1時間をマーケティングに充てる。コーディング前にやるのが理想。

| 時間 | 活動 | 具体的なアクション |
|------|------|------------------|
| 15分 | **投稿** | 4カテゴリから1つ選んで投稿 |
| 15分 | **エンゲージメント** | リプライ返信、他の開発者の投稿にコメント |
| 15分 | **コミュニティ** | Reddit、Discord、IndieHackersで価値を提供 |
| 15分 | **分析** | 何が反応良かったか確認、次の投稿を計画 |

### ステップ4: 週次/月次レポートテンプレート

#### 週次レポート（Xスレッド）

```markdown
📊 [プロダクト名] Week [N] レポート 🧵

1/5 今週の数字:
- MRR: $[金額] ([前週比])
- 新規ユーザー: [数]
- ページビュー: [数]

2/5 今週やったこと:
- [機能/改善1]
- [機能/改善2]
- [機能/改善3]

3/5 学び:
[今週の最大の学び]

4/5 来週の計画:
- [予定1]
- [予定2]

5/5 [プロダクト名] が気になったら:
[URL]
フィードバック大歓迎です 🙏
```

#### 月次収益レポート

```markdown
💰 [プロダクト名] [月] 収益レポート

## 数字
- MRR: $[金額] ([前月比])
- 新規有料: [数]
- チャーン: [数]
- ARR: $[金額]

## 今月のハイライト
1. [成果1]
2. [成果2]

## 課題
1. [課題1]
2. [課題2]

## 来月の計画
1. [計画1]
2. [計画2]

---
全ての数字はリアルです。透明性がインディー開発の文化。
```

### ステップ5: コンテンツカレンダー生成

1週間分のコンテンツカレンダーを生成する：

```markdown
| 曜日 | カテゴリ | 内容 |
|------|---------|------|
| 月 | 進捗共有 | 週末の開発成果 |
| 火 | 技術的学び | Tips/How-to |
| 水 | 進捗共有 | 機能リリース |
| 木 | ストーリー | なぜ作ったか |
| 金 | 収益透明性 | 週次レポート |
```
