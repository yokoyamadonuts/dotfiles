# ポケモン対戦構築スキル（くろこ式メタカバレッジ理論）

## 概要

ポケモン対戦（ランクマッチ）の構築を、環境のトップメタへの理論的対応から組み上げるフレームワーク。歴代最多最終1位（9回）のくろこ氏がSVで4回1位を取った構築理論を体系化したもの。

**核心思想**: 「トップメタに勝てないと安定しない。トップメタ全てに動ける1枠を見つけて、そこから構築を広げる」

## 5つの原則

### 原則1: 環境トップの特定

使用率上位3〜5体を正確に把握する。「こいつらに勝てないとまず話にならない」ポケモンを先に定義する。

> 「レギュHのトップ4はガチグマ、カイリュー、サーフゴー、ブリジュラス。この4体に勝てないとまず安定しない」

### 原則2: 全対応枠の発見

トップメタ全てに動ける1体を探す。技構成・持ち物・テラスタイプの組み合わせで複数の脅威に同時に回答できるポケモンを見つけることが構築の核。

> 「ラグラージが全部に行けるくね。あくび＋食いしばり＋ステロ＋守るで全対応できる」

### 原則3: 型ずらし

テンプレ型をコピーしない。情報が高速に共有される環境では、テンプレ型は見た瞬間に対処される。持ち物・技構成・テラスタイプ・努力値配分で環境の想定からずらす。

> 「全部のカイリューの型が違う。環境からずらすのが大事。テンプレはみんな見た瞬間に対処できるから」

### 原則4: 崩し分担（どちらか絶対通る理論）

受け構築や高耐久サイクルを崩すために、相互補完する2体の崩し枠を用意する。相手がどちらかを止めたらもう片方が通る構造にする。

> 「ガブとガチグマを絡めることによって絶対どっちか通る」

### 原則5: 理論先行

「なんとなく強そう」で組まない。トップメタへの選出パターンと立ち回りを理論的に埋めてから構築を完成させる。組んだ瞬間に勝てると確信できる状態が理想。

> 「組んだ瞬間に勝てるなって思った。全部の理論が噛み合っている」

## コアワークフロー

### ステップ1: 環境分析

ユーザーからルール（レギュレーション）と分析したい範囲を聞く。

```javascript
AskUserQuestion({
  questions: [{
    question: "どのルールの構築を組みますか？",
    header: "ルール",
    options: [
      { label: "シングル（レギュレーション指定）", description: "ランクマッチシングルバトル" },
      { label: "ダブル（レギュレーション指定）", description: "ランクマッチダブルバトル" },
      { label: "特殊ルール", description: "シーズン限定・公式大会ルール等" }
    ],
    multiSelect: false
  }]
})
```

次に環境のトップメタを特定する:
1. ユーザーが把握している使用率上位ポケモンを聞く
2. 上位3〜5体を**環境トップ**として定義する
3. よく見る並び（構築の軸となる2-3体のセット）も確認する

### ステップ2: 全対応枠の探索

環境トップ全てに動けるポケモン＋型を探す。

**探索の手順**:

1. **対応マトリクスを作る**: 候補ポケモンが各トップメタにどう動けるか整理する
2. **上位記事の研究**: 過去シーズンの1位構築記事を読み、各トップメタへの勝ち方を調べる
3. **技・持ち物の組み合わせ**: 全対応を実現する技4つ＋持ち物＋テラスタイプを検討する

```markdown
## 全対応枠の対応マトリクス

| 候補ポケモン | vs [トップ1] | vs [トップ2] | vs [トップ3] | vs [トップ4] | カバー率 |
|------------|-------------|-------------|-------------|-------------|---------|
| ○○○       | あくびで流す  | ステロ巻き    | 守るで様子見   | テラバで突破   | 4/4     |
| △△△       | 打ち合える    | きつい       | 有利         | テラス必要     | 3/4     |
```

**全対応枠に求める条件**:
- トップ4のうち最低3体に安定して動ける（カバー率75%以上）
- 行動の再現性が高い（運に依存しない）
- テラスタイプを切らなくても最低限動ける（テラスは他に回せる）

### ステップ3: 型ずらし設計

全対応枠と取り巻きの型をテンプレからずらす。

**ずらし方の3パターン**:

| パターン | 内容 | 実例 |
|---------|------|------|
| 努力値ずらし | S調整や耐久ラインを環境の想定外にする | 意地パオジアンの上を取る陽気スカーフミライドン |
| 技ずらし | テンプレ技を環境対応の技に差し替える | カイリューの身代わり＋エアスラ＋電磁波（対ヘイラッシャ特化） |
| 持ち物ずらし | 想定外の持ち物で対応範囲を変える | 風船サーフゴー（対キョジオーン＋地面一貫切り） |
| テラスずらし | 非標準テラスで相手の計算を狂わせる | フェアリーテラバセグレイブ（対コノヨザル特化） |
| タイミングずらし | 環境で注目される前のポケモンを先取り | 誰も使っていないテツノドクガを最終日に投入 |

### ステップ4: 取り巻きの構築

全対応枠を軸に、残り5枠を以下の役割で埋める。

**役割分担**:

| 役割 | 説明 | 選定基準 |
|------|------|---------|
| 初手要員 | 対面性能が高く安定して初手に出せる | スカーフ/タスキ/先制技持ち |
| クッション | 不利対面から引き先になれる | 高耐久/再生技/威嚇等 |
| 崩し枠A | 受けサイクルを破壊する | 高火力/積み技/一貫性の高い技 |
| 崩し枠B | 崩し枠Aと補完する（どちらか通る） | Aが止まる相手に強い |
| 補完枠 | 構築全体の穴を埋める | 特定の並び・ギミックへの回答 |

**崩し分担の設計**:
- 崩し枠Aが止まる条件を明確にする
- その条件で崩し枠Bが通ることを確認する
- 相手の選出で両方が止まる状況が存在しないことを検証する

### ステップ5: 選出パターンと対応表の検証

環境に多い構築タイプごとに選出パターンと立ち回り方針を整理し、穴がないか確認する。

**対応表の作成**:

```markdown
## 選出パターン表

| 相手の構築タイプ | 選出（先発/裏/裏） | 立ち回り方針 | テラス先 |
|----------------|------------------|------------|---------|
| 対面構築        |                  |            |         |
| サイクル構築     |                  |            |         |
| 受けループ      |                  |            |         |
| 積み展開        |                  |            |         |
| 壁展開         |                  |            |         |
| 天候パ         |                  |            |         |
```

**検証チェックリスト**:

- [ ] 使用率トップ5全てに対する選出パターンが存在する
- [ ] 各選出で「なぜ勝てるか」の理由を説明できる
- [ ] 全対応枠が機能しない場合（ラム持ち等）の裏プランがある
- [ ] 崩し枠2体で「どちらか必ず通る」構造が成立している
- [ ] テラスタイプの切り先が構築全体で競合していない
- [ ] 型にテンプレからのずらしが少なくとも1つ含まれている

穴が見つかったらステップ2（全対応枠の再検討）またはステップ4（取り巻き変更）に戻る。「組んだ瞬間に勝てる」と思えるまで繰り返す。

## アンチパターン

| やりがちな失敗 | 問題 | くろこ理論での回答 |
|-------------|------|-----------------|
| 好きなポケモン6体集め | トップメタへの回答がない | まずトップメタへの全対応枠から組む |
| テンプレ構築コピー | 対策済みで安定しない | 持ち物・技・テラスで必ずずらす |
| 感覚で組む | 穴に気づかず最終日に崩壊 | 選出パターン表で理論的に検証 |
| 崩し枠1体だけ | 受けに詰まされる | 崩し分担で「どちらか必ず通る」構造 |
| 全員にテラス切りたい | テラス権が競合して選出が歪む | テラスなしで動ける全対応枠を軸にする |
| 全方位に薄く対策 | 何にも勝ちきれない | トップ4に絞って厚く対応する |
