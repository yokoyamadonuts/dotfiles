# ポケモン対戦 構築・選出スキル

## 概要

ポケモン対戦の構築（パーティ作成）と選出（3-4体選び）を支援する。シングル・ダブル両対応。

最初にルールを確認する:

```javascript
AskUserQuestion({
  questions: [{
    question: "どのルールの構築を組みますか？",
    header: "ルール",
    options: [
      { label: "シングルバトル", description: "ランクマッチ・仲間大会等" },
      { label: "ダブルバトル", description: "ランクマッチ・公式大会(VGC)等" },
      { label: "選出相談のみ", description: "既存構築の選出パターンを整理したい" }
    ],
    multiSelect: false
  }]
})
```

- **シングル** → Part 1（くろこ式構築論）＋ Part 3（選出論）を使用
- **ダブル** → Part 2（キヌガワ式構築論＋2匹軸構造論）を使用
- **選出相談** → Part 3（選出論）のみ使用

## Part 1: シングル構築論（くろこ式メタカバレッジ理論）

歴代最多最終1位（9回）のくろこ氏がSVで4回1位を取った構築理論。

### 5つの原則

**原則1: 環境トップの特定**
使用率上位3〜5体を把握し「こいつらに勝てないと話にならない」ポケモンを定義する。

> 「レギュHのトップ4はガチグマ、カイリュー、サーフゴー、ブリジュラス。この4体に勝てないとまず安定しない」

**原則2: 全対応枠の発見**
トップメタ全てに動ける1体を探す。技構成・持ち物・テラスの組み合わせで複数の脅威に同時回答できるポケモンが構築の核。

> 「ラグラージが全部に行ける。あくび＋食いしばり＋ステロ＋守るで全対応できる」

**原則3: 型ずらし**
テンプレ型をコピーしない。持ち物・技・テラス・努力値で環境の想定からずらす。

> 「全部のカイリューの型が違う。テンプレはみんな見た瞬間に対処できるから」

**原則4: 崩し分担（どちらか絶対通る理論）**
相互補完する2体の崩し枠を用意。相手がどちらかを止めたらもう片方が通る構造にする。

> 「ガブとガチグマを絡めることで絶対どちらか通る」

**原則5: 理論先行**
トップメタへの選出パターンと立ち回りを理論的に埋めてから完成させる。

> 「組んだ瞬間に勝てるなって思った。全部の理論が噛み合っている」

### シングル構築ワークフロー

#### S-1. 環境分析
ユーザーから使用率上位ポケモンと多い並びを聞き、トップ3〜5体を定義する。

#### S-2. 全対応枠の探索
対応マトリクスでトップメタへのカバー率を可視化する。

```markdown
| 候補ポケモン | vs [トップ1] | vs [トップ2] | vs [トップ3] | vs [トップ4] | カバー率 |
|------------|-------------|-------------|-------------|-------------|---------|
| ○○○       | あくびで流す  | ステロ巻き    | 守るで様子見   | テラバで突破   | 4/4     |
```

条件: カバー率75%以上、運に依存しない、テラスなしでも最低限動ける。

#### S-3. 型ずらし設計

| パターン | 実例 |
|---------|------|
| 努力値ずらし | 意地パオの上を取る陽気スカーフミライドン |
| 技ずらし | カイリューの身代わり＋エアスラ＋電磁波 |
| 持ち物ずらし | 風船サーフゴー（地面一貫切り） |
| テラスずらし | フェアリーテラバセグレイブ（対コノヨザル） |
| タイミングずらし | 誰も使っていないテツノドクガを先取り |

#### S-4. 取り巻きの構築
残り5枠を役割で埋める: 初手要員 / クッション / 崩し枠A / 崩し枠B / 補完枠。

#### S-5. 選出パターン表の検証
Part 3（選出論）の手法で全構築タイプへの選出を検証する。穴があればS-2〜S-4に戻る。

### くろこ式の実績

| シーズン | ルール | 全対応枠 | ずらし | 崩し分担 |
|---------|-------|---------|-------|---------|
| S4 | レギュB | カイリュー（エアスラ電磁波身代わり） | テツノドクガ先取り | セグレイブ（フェアリーテラバ） |
| S14 | レギュF | ガチグマ（残飯） | ライコ（鋼テラスヘビボン） | カイリュー（メガネ） |
| レギュH | レギュH | ラグラージ（あくびステロ守る食いしばり） | 守るでブラム透かし | ガブリアス＋ガチグマ月輝 |
| レギュG | レギュG | ミライドン（陽気スカーフ氷テラバ） | 氷テラス先取り | ホノボノポン＋パオジアン |

## Part 2: ダブル構築論

### キヌガワ式6ステップ構築法

日本チャンプ＆南米チャンプのキヌガワ（UMA）が実践する構築手順。LAIC優勝構築を例にした解説に基づく。

#### D-1. 軸を1匹決める
好きなポケモン、使いたいポケモン、環境的に刺さっていそうなポケモン、何でもよい。

#### D-2. 軸の性質を分析する
**種族値・タイプ・特性・覚える技**の4つを分析し、そのポケモンを最も強く使える状況を考える。

考える内容:
- このポケモンの**理想の動き**は何か（例: ブラッドムーンかハイパーボイス連打）
- 理想を実現するのに必要なサポートは何か（追い風/トリル/猫騙し/この指/手助け等）
- サポート候補の中で最も相性が良いポケモンを**2体目**として決定する

> 例: ガチグマ（S低い）→ トリルが最適 → トリル要員としてテブリムを2体目に

#### D-3. 攻めの補完を考える
軸のポケモンでは打点が出せない相手（半減タイプ等）に弱点をつけるポケモンを探す。**攻めを受けより優先**する。

> 例: ガチグマのメインウェポンを鋼が半減 → 鋼に弱点をつけるポケモンが必要

#### D-4. 受けの補完を考える
攻めの補完と受けの補完を**兼ね備えるポケモン**がベスト。特に重要なのは**全体技の一貫を切ること**（地震・熱風・なだれ・ハイパーボイス・濁流・吹雪等）。

受け補完の手段:
- タイプ補完で半減/無効にする（ベスト）
- アイテムで耐える（突撃チョッキ・原子力等）
- 壁や威嚇で火力を下げる
- 爆速高火力で受けずに倒しきる（攻撃は最大の防御）

**重要**: この工程で候補に上がったポケモンは**全てメモしておく**。最終工程で戻ってくることが非常に多い。

> 例: カラミンゴ（地面一貫切り＋ワイドガード＋サーフゴーに強い）。LAICではブリジュラスとカラミンゴが最終局面で入れ替わった。

#### D-5. 上から殴る手段があるか確認する
素で早いポケモンまたはスカーフ持ちが構築にいるか確認する。トリル構築でも素早いポケモンを入れたほうが安定する（トリル止められた時の保険）。

> 例: バクフーン（環境的にやや早い＋ゴーストで格闘耐性＋鋼に打点）

#### D-6. 仮想敵への選出4体を確認する（∞回繰り返す）
環境に多い構築を思い浮かべ、それに出せる4体が存在するか確認する。出せないなら6体目（またはそれ以前の枠）を調整する。

**この工程を100億回繰り返す**のが強い構築を作る秘訣。繰り返す中で条件が増えて1枠では足りなくなったら、**過去に採用したポケモンを見つめ直し**、採用理由の軸はぶらさずに追加条件を満たすポケモンに入れ替える。

最終的に完璧な構築は組めない → **環境読みで切り捨てる相手を決める**。

### 2匹軸構造論（喰い断式）

ダブルバトルの構築骨格に関する理論。

**2匹軸**: 2体セットで運用する前提の並び（例: トルネウーラ、神カイナ、パオカイリュー）。

**現環境で強い構築構造**:
- **2匹軸×3**: 3つの2匹セットを構築に内包する（例: 神+カイナ / トルネ+ウーラ / ランド+もう1体）
- 選出時にどの2匹セットを使うか選べる = 実質3つのパーティを1つで体験
- ×3が必須ではなく、2匹軸×2+1+1の構成も多い

**避けるべき構造**:
- 2匹軸+4（ドレディアコータス+4のような特化型）→ 軸を止められると残り4体が弱い

**選出中の意識**:
- 2匹軸のセットは崩さず選出する
- 試合中も2匹軸が並んでいる状態を維持する（片方が倒されたら別の2匹軸が成立するように裏を構成）

## Part 3: 選出論（シングル・ダブル共通）

見せ合い画面での思考フレームワーク。バンビー、いろは、くろこの3人の選出過程から抽出。

### 選出の4ステップ

#### 1. 刺さり即判断
相手の6体を見て「明らかに刺さっている」と「明らかに刺さっていない」ポケモンを瞬時に判断する。

#### 2. 絶対出す/絶対出さないを決める
- **絶対投げるポケモン**を先に確定（例: 天然2体いるから物理ゴリ押しは通らない → 特殊エースは確定）
- **絶対投げないポケモン**を即除外（例: パルシェンは100%投げない）
- 残りの枠で調整する

#### 3. 初手は4匹以上に有利なポケモン
初手に置くポケモンは相手6体のうち4体以上に有利に動けるポケモンを選ぶ。残り2体が来たら裏で対処する。

初手選定の注意:
- **初手テラスを切りたくない** → テラスなしで動ける初手が理想
- **引きが安定しない初手は避ける** → ヘイラッシャの守るあくび等に面倒になるドラパルト等

#### 4. 3体で6体を見る
選出した3体（ダブルなら4体）で相手の6体全てにある程度ケアできる構成を目指す。崩し手段も忘れない。

### 選出の応用原則

- **崩してくるポケモンを読む**: 相手視点で「何で崩しに来るか」を考え、その裏をかく
- **引けばいいわけではない**: クッションで受け回すだけでなく対面で戦えるポケモンも必要
- **上位プレイヤーでも選出は分かれる**: 唯一の正解はなく、自分の構築の動かし方に合った選出が正しい

## アンチパターン

| やりがちな失敗 | 問題 | 回答 |
|-------------|------|------|
| 好きなポケモン6体集め | トップメタへの回答がない | まずトップメタへの全対応枠から組む |
| テンプレ構築コピー | 対策済みで安定しない | 持ち物・技・テラスで必ずずらす |
| 感覚で組む | 穴に気づかず最終日に崩壊 | 選出パターン表で理論的に検証 |
| 崩し枠1体だけ | 受けに詰まされる | 崩し分担で「どちらか必ず通る」構造 |
| 候補ポケモンをメモしない | 最終局面で戻れない | D-4で候補は全てメモ |
| 2匹軸+4で組む（ダブル） | 軸止められたら終わり | 2匹軸×3構造で柔軟に |
| トリル特化で早いポケモン0 | トリル止められたら詰む | 素で早いポケモンも1体入れる |
| 全員にテラス切りたい | テラス権が競合して選出歪む | テラスなしで動ける軸を中心にする |
| 選出で初手テラス前提 | テラス読みで崩される | 初手テラスを切らなくていい選出を優先 |
