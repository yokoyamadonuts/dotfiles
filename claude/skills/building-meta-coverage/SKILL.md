# ポケモン対戦 構築・選出・立ち回りスキル

## 概要

ポケモン対戦の構築（パーティ作成）・選出（3-4体選び）・立ち回り（対戦中の判断）を支援する。シングル・ダブル両対応。トッププレイヤーの構築記事・理論記事から抽出した知見に基づく。

## Part 1: シングル構築論

### くろこ式5原則

**原則1: 環境トップの特定** — 使用率上位3〜5体を「こいつらに勝てないと話にならない」として定義。

**原則2: 全対応枠の発見** — トップメタ全てに動ける1体を探す。カバー率75%以上、運に依存しない、テラスなしでも動ける。

**原則3: 型ずらし** — テンプレからずらす。ただし**全部を変えるのではなく勝負を分ける1-2箇所だけ**ずらす（ぼのぼに「ずらせスタン」理論）。

> ずらし方: 努力値（耐久ラインで確定数を変える）/ 技（テンプレ技を環境対応技に差替）/ 持ち物 / テラスタイプ / タイミング（環境注目前に先取り）

**原則4: 崩し分担** — 相互補完する2体の崩し枠で「どちらか絶対通る」構造を作る。

**原則5: 理論先行** — 選出パターン表を理論的に埋めてから完成。「組んだ瞬間に勝てる」確信を持てる状態が理想。

### シングル構築ワークフロー

#### S-1. 環境分析
使用率上位ポケモンと多い並びを把握。**前シーズンの上位構築をレンタルで回して研究**するのが最も確実。

#### S-2. 6枠の役割配分（スミス式 2-2-1-1）

| 段階 | 枠数 | 内容 | 目標 |
|------|------|------|------|
| 軸 | 2体(AB) | 最も活躍させたい並び。相性補完の良い2体 | 構築の勝ち筋の核 |
| 取り巻き | 2体(CD) | 軸が苦手なポケモンに回答する2体 | 4体で環境の7-8割に勝てる |
| 補完 | 1体(E) | 残りの弱点を埋めるピンポイント枠 | 穴を塞ぐ |
| 遊撃 | 1体(F) | 自由枠（メタ読み/構築偽装/初手の選択肢拡張） | 柔軟性を持たせる |

**初手要員は必ず2枠用意する**。相手構築に応じて初手を変えられる柔軟性が重要（スポンジ式: 炎オーガポン＋サーフゴーの2枚初手体制）。

#### S-3. 全対応枠＋崩し分担の検証

対応マトリクスでトップメタへのカバー率を可視化:
```markdown
| 候補 | vs [トップ1] | vs [トップ2] | vs [トップ3] | vs [トップ4] | カバー率 |
|------|-------------|-------------|-------------|-------------|---------|
```

崩し枠A・Bが止まる条件を列挙し、両方が止まる状況がないことを検証。

#### S-4. 型ずらし設計 → S-5. 選出パターン表の検証

Part 3（選出論）の手法で全構築タイプへの選出を検証。穴があればS-2に戻る。

### 構築アーキタイプ別テンプレート（Smogon準拠）

| アーキタイプ | 構成 | 勝ち筋 |
|------------|------|-------|
| **Balance** | Sweeper 0-1 / Breaker 1-2 / Wall 2-3 / SR setter 1 / 除去 1 | ダメージレースの総量 |
| **Hyper Offense** | Sweeper 2-4 / Breaker 1-3 / SR setter 1 | 積みエースで全抜き |
| **VoltTurn** | U-turn 2 / Volt Switch 2 / SR setter 1 / 除去 1 | 有利対面を作り続ける |
| **Stall** | Wall 4-5 / 毒撒き1 / 除去1 | 定数ダメージで削り切る |

## Part 2: ダブル構築論

### キヌガワ式6ステップ

**D-1. 軸を1匹決める** — 好き/使いたい/刺さっている、何でもよい。

**D-2. 軸の性質分析** — 種族値・タイプ・特性・技の4つから「理想の動き」を定義し、それを実現するサポートポケモンを2体目に。

**D-3. 攻めの補完** — 軸で打点が出ない相手に弱点をつけるポケモン。**攻めを受けより優先**。

**D-4. 受けの補完** — 攻め補完と兼ねるのがベスト。特に**全体技（地震・熱風・なだれ・ハイボ・濁流）の一貫を切る**こと。候補は**全てメモ**（最終工程で戻ることが多い）。

**D-5. 上から殴る手段** — 素早いポケモンかスカーフ持ちを確認。トリル構築でも1体は入れる。

**D-6. 仮想敵への選出4体を確認（∞回繰り返す）** — 条件が増えて1枠で足りなくなったら、既存枠を「採用理由の軸はぶらさずに」追加条件を満たすポケモンに入れ替える。完璧は無理→**環境読みで切り捨てる相手を決める**。

### 2匹軸構造論

- **2匹軸×3**: 3つの2匹セットを内包（例: 神+カイナ / トルネ+ウーラ / ランド+α）
- 選出時にどのセットを使うか選べる＝実質3パーティ
- 試合中も2匹軸が並んでいる状態を維持する
- **見せ駒戦略**: 6体目を実際に出さない枠にして相手の対策リソースを分散させる（Luca世界大会優勝: ルナアーラ不選出）

### ダブル特有のテクニック

- **おんみつマント**: ねこだまし無効化で初手おいかぜ/トリルを安定させる
- **このゆびとまれ＋エース**: リダイレクトでエースを守りつつ横のエースで削る
- **ねこだまし**: 相手のS操作役を1T止めてこちらの展開を通す
- **フィールドシナジー軸**: エレキフィールド等で複数体を同時ブースト

## Part 3: 選出論

### 見せ合い3ステップ

**Step 1: コンセプト把握** — 相手の6体から構築タイプを読む（トリル/積み/サイクル等）。ポケモンの組み合わせから型を推定する。

**Step 2: 刺さり即判断 → 絶対出す/出さないを決める**
- 明らかに刺さっている/いないポケモンを瞬時に判断
- 絶対投げるポケモン確定 → 絶対投げない除外 → 残り枠で調整

**Step 3: 初手＋裏を決める**
- 初手は相手6体のうち**4体以上に有利**なポケモン
- 初手テラスを切らなくて済む選出が理想
- 3体（ダブルなら4体）で相手の6体全てにケアできる構成

### くろこ式選出のポイント

- **即負けしない選出が最優先** — 特定の1体に全員倒される展開を避ける
- **処理手段が「テラスタル頼み」「運頼み」の時点で選出が破綻**している
- 選出は唯一の正解があるわけではない。自分の構築の動かし方に合った選出が正しい

### 選出率の管理

上位プレイヤーは構築記事に各ポケモンの選出率を記載する。**6体全員が30%以上の選出率**を持つ構築が理想。選出率0%の枠は構築の無駄枠（見せ駒戦略は例外）。

## Part 5: サイクル理論

### サイクルの基本

- 交代しながらダメージレースに勝ち続けるのがコンセプト
- **技の一貫性を切る**: 相手の主力技を半減以下で受けられるポケモンを必ず用意
- 2体でサイクルを回し、削った後にエースを通す（2+1パターン）

### 交代のコスト

- 交代するたびにステロ・毒等の蓄積ダメージが増加
- 急所リスクも交代回数に比例して増加
- **「交代しないこと」にも価値がある** — 無駄な交代はサイクル崩壊の原因

### 有利対面の作り方

- とんぼがえり/ボルトチェンジで安全に裏を着地させる
- あくびで流して有利対面を作る
- ステルスロックで交代コストを相手に押し付ける

## Part 6: EV調整理論

### 調整の優先順位

1. **素早さライン**: 環境の仮想敵を意識。「何を抜けるか」を明確にする
2. **耐久ライン**: 仮想敵の攻撃を耐える調整（例: 「A252ガブの地震確定耐え」）
3. **火力ライン**: 仮想敵を確定Nで落とせるか（例: 「H252レヒレをアイヘ確2」）
4. **余り配分**: HP=防御+特防のとき総合耐久最大化（数学的最適解）

### 調整の原則

- **252/252/4で十分な場合が多い**。複雑な調整が必要なのは明確な仮想敵がいる時だけ
- 意味のない調整は調整と呼ばない。「なぜこの数値か」を説明できること
- 物理受けはHP×防御、特殊受けはHP×特防を最大化
- **低い方の防御に先に振る**のが効率的（Smogon鉄則）

## Part 7: 構築完成度チェックリスト

構築が完成したら以下を確認する:

- [ ] 環境トップ5それぞれに対する明確な回答がある
- [ ] 選出パターンが3つ以上ある（固定選出にならない）
- [ ] テラスなしで勝てる試合展開が描ける
- [ ] 物理・特殊のバランスが取れている（3:3 or 2:2+両刀）
- [ ] 先制技持ちが1体以上いる（ストッパー性能）
- [ ] ステロ・状態異常への耐性がある
- [ ] 特定の1体に全員倒される構成になっていない
- [ ] 初手要員が2枠ある
- [ ] 6体全員の選出率が30%以上になりそうか
- [ ] 「組んだ瞬間に勝てる」と思えるか

## アンチパターン

| やりがちな失敗 | 回答 |
|-------------|------|
| 好きなポケモン6体集め | まずトップメタへの全対応枠から組む |
| テンプレ丸コピー | 1-2箇所だけずらす（全部変えない） |
| 感覚で組む | 選出パターン表で理論的に検証 |
| 崩し枠1体だけ | 崩し分担で「どちらか通る」構造 |
| ギミックを強要される構築 | ギミックなしで動ける設計＋能動的にギミックを切って勝ち筋を太くする |
| 選出率0%の枠がある | 6体全員30%以上を目標（見せ駒は例外） |
| 候補ポケモンをメモしない | D-4で候補は全てメモ。最終工程で戻る |
| 初手要員が1枚だけ | 初手2枠体制で相手に応じて使い分ける |
| 全方位に薄く対策 | 環境読みできつい相手を割り切る |
| 無駄な交代を繰り返す | 交代のコストを意識。交代しない価値もある |
