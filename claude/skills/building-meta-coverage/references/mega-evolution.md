# メガシンカ論（ORAS・Champions等のメガシンカ環境）

対戦中1体だけポケモンをメガシンカさせ、種族値・特性・タイプが変化するギミック。メガストーンの持ち物枠消費と1試合1回の制約がある。

## メガシンカの3分類

| 使い方 | 説明 | 構築への影響 |
|-------|------|------------|
| **エース型メガ** | メガシンカで火力・速度が上がり、メインアタッカーとして運用 | 構築の勝ち筋の核。メガ枠=エース |
| **サポート型メガ** | メガシンカで特性が変わり、サポート性能が向上（例: メガフシギバナの厚い脂肪） | 受け回しやサイクルの軸 |
| **対面型メガ** | メガシンカで耐久と火力を両立し、広い範囲と殴り合える | 対面構築の中心 |

## メガシンカ選定の基準

- **メガ枠は構築の軸**: 6体の中で最も活躍するポケモンにメガストーンを持たせる
- **メガ前の素早さに注意**: メガシンカはターン中に発動するため、メガ前のSで行動順が決まる（初ターンのみ）
- **持ち物枠の消費**: メガ枠以外の5体で持ち物の多様性を確保する必要がある
- **メガシンカしない選択**: 相手の構築によってはメガせずに通常の持ち物持ちとして運用する柔軟性も考慮

## 構築における設計

出力テンプレートに以下を含める:

```markdown
## メガシンカ設計
- メガ枠: [ポケモン] → [メガポケモン]
  - メガ前特性: [特性] / メガ後特性: [特性]
  - メガ前S実数値: [値] / メガ後S実数値: [値]
  - 役割変化: [メガ前の役割] → [メガ後の役割]
- メガしない場合のプラン: [メガ枠を選出しない/メガしないで戦う場面]
```

## 選出への影響

- メガ枠は選出率が最も高くなる傾向 → 相手もメガ枠の対策を最優先で行う
- メガ枠を出さない選出パターンも1つは用意する（相手のメタを外す）
- ダブルバトルでは「メガ枠＋サポート」の2匹軸が基本

## メガシンカミラー

- 同じメガポケモン同士の対面（メガガルーラミラー等）は環境の中心課題になりやすい
- ミラーに強い型（S振り/耐久振り等）が環境で評価される
- メガ枠の選択自体が環境読みの一部

## アンチパターン

| 失敗 | 回答 |
|------|------|
| メガ枠を毎試合絶対出す前提 | メガなし選出も1パターン用意する |
| メガ前Sを考慮しない | 初ターンはメガ前Sで行動。遅いメガは初手で不利になりうる |
| メガ枠以外が持ち物なし同然 | メガ枠1体分の持ち物ロスを他5体の持ち物選定で取り返す |
| メガ枠の対策が薄い | 環境で流行るメガへの回答を構築に必ず含める |
