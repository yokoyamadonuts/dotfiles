# X（Twitter）成長スキル

## 概要

X（Twitter）アカウントの成長を3段階フレームワークとポスト作成支援で加速する。70人→10,000フォロワーを5か月で達成した実践知を体系化。フォロワー規模に応じたフェーズ診断、戦略提案、ポスト作成・添削、型の仮説検証サイクルを提供する。

## 3段階成長フレームワーク

### Phase 1: 引用リポスト中心（0〜3,500フォロワー）

**目的**: 認知獲得と学習

- **やること**: インフルエンサーや共感するポストへの引用リポストを中心に活動する
- **狙い**: 元ポストのオーディエンスに自分の存在を認知させる
- **学び**: 何が反応を得るか、どんな文体が自分に合うかを試行錯誤で学ぶ
- **引用の質**: 単なる「わかる」ではなく、自分の経験や独自解釈を乗せて咀嚼する
- **量の目安**: 1日3〜5件の引用リポスト

### Phase 2: 自前ポスト試行（〜4,500フォロワー）

**目的**: 独自視点の確立と大量試行

- **やること**: 引用リポストを減らし、自前のオリジナルポストを量産する
- **狙い**: 自分の声で語れるテーマとスタイルを確立する
- **試行錯誤**: 100本中5本当たればいい。打率より打席数を重視する
- **分析**: 伸びたポストと伸びなかったポストの差分を言語化する
- **量の目安**: 1日1〜3件のオリジナルポスト

### Phase 3: 型の構築・拡張（〜10,000+フォロワー）

**目的**: 仮説検証による打率向上

- **やること**: 伸びたポストからパターン（型）を抽出し、意図的に再現・拡張する
- **狙い**: 再現性のある勝ちパターンを武器にする
- **型の運用**: 基本型の捻り、組み合わせ、全く異なるアプローチの混合
- **仮説検証**: 「この型 × このテーマなら伸びるはず」を検証し続ける
- **量の目安**: 1日1〜2件（質重視）+ 週1で実験的ポスト

### ステップ2: フェーズ判定と戦略提案

フォロワー数に基づいてフェーズを判定し、現在やるべきことを具体的に提案する：

- **Phase 1の場合**: 引用すべきアカウントの選定基準、引用テンプレート、1日のルーティン提案
- **Phase 2の場合**: テーマの絞り込み、ポスト構造のフレームワーク、試行の振り返り方法
- **Phase 3の場合**: 型の抽出ワークショップ、仮説検証サイクルの設計、拡張パターンの提案

### ステップ3: ポスト作成支援

フェーズに応じたアプローチでポスト作成を支援する。

#### Phase 1向け: 引用リポストの作成・添削

引用リポストの質を高める：

1. **元ポストの咀嚼**: 表面的な同意ではなく、WHYまで掘り下げる
2. **自分の経験を乗せる**: 「自分の場合は〜」「以前〜した時に」で具体性を加える
3. **独自解釈を加える**: 元ポストと少し異なる角度から切り込む
4. **一文で刺す**: 最初の一文で引きを作る

添削の観点：
- 元ポストの本質を捉えているか
- 自分ならではの視点が入っているか
- 読んだ人が「この人フォローしたい」と思うか

#### Phase 2向け: 自前ポストの作成・添削

「ポスト作成ガイドライン > 自前ポストの構造」のフック→本文→CTAフレームワークでポストを組み立てる。

添削の観点：
- フックは十分に強いか（スクロールを止められるか）
- 本文に独自視点があるか（誰でも書ける内容になっていないか）
- 短文で完結しているか、スレッドにすべきか

#### Phase 3向け: 型のパターン化・応用

伸びたポストを分析して型を抽出・拡張する：

1. **型の抽出**: 伸びたポスト群から共通パターンを特定（構造、テーマ、文体）
2. **型の命名**: パターンに名前をつけて再利用可能にする（例：「逆説型」「Before/After型」「数字型」）
3. **型の拡張**: 基本型を別テーマに応用する、2つの型を組み合わせる、あえて型を崩す

### ステップ4: 型の仮説検証サイクル

過去のポスト実績から型を進化させる継続的なサイクル：

1. **データ収集**: ユーザーから過去のポスト実績（いいね数、RT数、インプレッション）を聞く
2. **パターン抽出**: 伸びたポスト上位5件の共通点を分析する
3. **仮説生成**: 「この型 × このテーマ × この時間帯」で伸びるはず、という仮説を立てる
4. **ポスト提案**: 仮説に基づく次のポスト案を3パターン提示する
5. **振り返り**: 結果を踏まえて仮説を更新する

## ポスト作成ガイドライン

### 引用リポストのコツ

- **悪い例**: 「めっちゃわかる」「これ大事」→ 付加価値ゼロ
- **良い例**: 「元ポストの〇〇に加えて、自分は△△だと考える。なぜなら〜」→ 独自視点あり
- 元ポストの3倍の文量を目安にする
- 引用元の著者が「いいね」したくなる内容を意識する

### 自前ポストの構造

```
[フック: 1行目で止まらせる]

[本文: 価値提供 / 経験 / 具体例]

[CTA: 問いかけ / 行動喚起]
```

フックのパターン：
- **断定型**: 「〇〇は△△だ。」
- **逆説型**: 「〇〇だと思ってたけど、実は△△だった。」
- **数字型**: 「〇〇を3年続けてわかった△△のこと。」
- **問いかけ型**: 「なぜ〇〇なのに△△なのか？」
- **告白型**: 「正直に言うと、〇〇だった。」

### 型の拡張テクニック

- **テーマ替え**: 同じ構造で違うテーマに適用する
- **組み合わせ**: 2つの型を掛け合わせる（逆説 × 数字 = 「3年やって気づいた、〇〇は逆効果だった」）
- **反転**: あえて型の逆をやって反応を見る
- **スレッド化**: 1ポストで伸びた型を5ツイートのスレッドに展開する
