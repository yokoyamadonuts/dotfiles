# /build-fix - ビルドエラー修正コマンド

エラー収集・分類・修正パターンの知識はすべて `build-error-resolver` エージェントが持つ。
本コマンドは引数解釈と結果報告のみを担う。

## 使い方

```
/build-fix              # すべてのビルドエラーを修正
/build-fix --type-only  # 型エラーのみ修正
```

## 実行フロー

1. `build-error-resolver` エージェントを起動し、以下を指示する:
   - 対象範囲: `--type-only` なら型チェックエラーのみ、それ以外はすべてのビルドエラー
   - 修正方針: 最小限の変更でビルドを通す（リファクタリング・パフォーマンス改善・ロジック変更はしない）
   - 優先順位: 型不一致・null/undefined（高）→ インポート・設定（中）→ 依存関係（低）
2. エージェントの修正完了後、ビルド・型チェックが通ることを確認する
3. 修正サマリー（修正したエラー数・変更ファイル・残存エラー）を提示する

残存エラーがある場合は、原因と推奨対応を報告して終了する（無限に修正ループしない）。
